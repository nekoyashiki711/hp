# nekoyashiki 公式サイト 制作指示書（Claude Code 向け）

このフォルダのデザインどおりに、nekoyashiki（宮城県仙台市）の公式サイトを実装してください。
デザインの正は `design/*.dc.html`、画像は `assets/` です。文言は `.dc.html` 内のテキストをそのまま使ってください（勝手に書き換えない）。

## 4. 背景の猫アニメーション（重要）

参考サイト（https://www.mitonedesign.jp/）のように、**背景のレイヤーで猫のイラストがスクロールに合わせて静かに動く**演出を入れる。主張させず、気づく人だけが気づく程度に。

### 4.1 画像（`assets/cats/`）
| ファイル | ポーズ | 主な使い場所 |
|---|---|---|
| `cat-sit.svg` | 正面で座る | ヒーロー、フッター |
| `cat-walk.svg` | 歩く（横向き） | 入口カードの帯、ご相談の流れ |
| `cat-loaf.svg` | 香箱座りで眠る | お悩み |
| `cat-peek.svg` | ふちからのぞく | できること、最後のCTA箱の上 |
| `cat-back.svg` | 後ろ姿 | 選ばれる理由 |
| `cat-curl.svg` | 丸くなって眠る | 代表メッセージ、わたしたち |

- すべて同じ作り：線 `#7CC3A7` 1.6px（`vector-effect: non-scaling-stroke`）、塗り `#F1F8F5`、足元に薄いぼかし影（`#8DCDB4` 不透明度 .3）。
- 色や線の太さは変えない。インライン SVG か `<img>` で使う（装飾なので `aria-hidden="true"` / `alt=""`）。

### 4.2 配置と動き（トップページ）
すべて**本文の後ろ**に置く。白い余白の場所にだけ置き、色付きの帯（`#F3F8F6`・緑・ミント）の後ろを通り抜けてよい。

| 場所 | 画像 | 位置（PC） | 幅 | 動き |
|---|---|---|---|---|
| ヒーロー | cat-sit | 2枚の写真の間（左から約42%） | 120px | 縦にゆっくり上昇 ±70px、傾き −3°→3° |
| お悩み | cat-loaf | 見出しの下・左下 | 280px | 縦 ±120px（本文より遅く沈む） |
| できること | cat-peek | セクション上端の右寄り | 160px | 画面に入ると下から20px せり上がって止まる（1回だけ） |
| 選ばれる理由 | cat-back | 見出し行の右側 | 140px | 縦 ±90px、傾き 2°→−2° |
| ご相談の流れ | cat-walk | STEP 線の上 | 120px | **スクロール量に合わせて STEP01→STEP04 の上を左から右へ歩く**（横移動 0→100%）。歩幅に合わせて上下2px の揺れ |
| 代表メッセージ | cat-curl | ミント枠の右下に重ねる | 140px | 縦 ±40px のみ |
| 最後のCTA | cat-peek | 白い箱の上端・右から96px | 96px | 画面に入ると箱のふちからのぞく（−24px→0、1回だけ） |
| フッター | cat-sit | 大きな「NEKOYASHIKI」の上・右寄り | 90px | 縦 ±50px |

- 同時に画面に見える猫は**2匹まで**。
- 下層ページ：事業者様＝cat-walk（流れ）、個人様＝cat-loaf（ヒーロー右下）、わたしたち＝cat-curl（屋号の由来）、採用情報＝cat-sit（代表メッセージ）を各1〜2匹。
- **スマホ**：トップは3匹に絞る（ヒーロー cat-sit 72px／ご相談の流れ cat-walk 96px／CTA cat-peek 64px）。動く量は PC の60%。

### 4.3 実装方法
- 動かすのは `transform` と `opacity` だけ（レイアウトを動かさない）。`will-change: transform`。
- 第一候補は CSS のスクロール連動アニメーション（`animation-timeline: view()`）。未対応ブラウザ（Firefox、古い Safari）向けに、`IntersectionObserver` と `requestAnimationFrame` の軽い JS で同じ動きを再現する。GSAP ScrollTrigger を使ってもよい（その場合は1本に統一）。
- 縦の移動量は「要素が画面中央に来たとき 0」になるよう、画面内の位置から計算する（ページ全体のスクロール量に比例させない）。
- 背景レイヤーは各セクション内に `position: absolute; z-index: -1; pointer-events: none;` で置く。親は `position: relative; isolation: isolate;`。スクロールの基準が狂わないよう、レイヤーには `overflow: hidden` ではなく `overflow: clip` を使う。
- **`prefers-reduced-motion: reduce` のときは動かさず、定位置に静止表示。**
- 参考実装：`design/Main.dc.html` の「BACKGROUND CATS」ブロック（試作）。

## 5. 品質の条件

- スマホで最初に見たときの表示速度（LCP）を 2.5秒以内にする。画像は遅延読み込みにし、猫の SVG は合計 15KB 以内に収める。
- アクセシビリティ：文字のコントラスト 4.5:1 以上、キーボードで操作できる、フォーカスが見える、装飾画像は読み上げ対象外。
- SEO：ページごとに title と description を付け、OGP を設定する。ローカルビジネスの構造化データ（LocalBusiness：住所・電話・営業エリア＝宮城県）も入れる。採用情報は noindex。
- ブラウザ：Chrome／Safari（iOS 16以上）／Edge／Firefox の最新版。
