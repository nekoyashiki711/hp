## 守ること

- **デザインルール**は次のとおりです（作り直しで変える場合は、この部分を書き換えてから貼ってください）。迷ったら `Business.dc.html` と `About.dc.html` に合わせます。

  - 角丸：写真・カード 4px、ボタン 999px。
  - 書体：和文 Zen Maru Gothic（400/500/700）、欧文・数字 Helvetica Neue → Helvetica → Arial。本文16px以上（PC17px）、行間1.9〜2.1。
  - レイアウト：最大幅1360px、左右余白40px（スマホ20px）、セクション上下余白 PC140px／スマホ72px。
  - セクション見出し：短い横線（32×4px #333）＋英字ラベル（字間.16em）→ 和文見出し。
  - ヘッダー・フッター・スマホ下部の固定バーは既存のものをそのまま使う。**メニューに「コラム」を追加**しました（事業者様／個人様／できること／実績／わたしたち／コラム／お問い合わせ）。
  - 下層ページの上部は既存と同じ「パンくず → 英字ラベル → 大見出し → リード文」。
  - ボタン・リンクのタップ領域は44px以上。文字のコントラストは4.5:1以上。
- **公式LINEはまだありません。** LINEボタンは描かず、「フォームで相談する」（緑ボタン）と「電話で相談する」（白い枠線ボタン）の組み合わせにしてください。
- **写真はまだありません。** 写真の枠は、薄いミントの面に小さなドット柄と、中央に緑の線画の猫マーク（logo-mark）を薄く置いた「準備中の面」で表現してください（「DUMMY」とは書かない）。
- 背景の猫（`Cats.dc.html`）は各ページ1〜2匹まで。白い余白にだけ置く。
- **書いていない事実を足さないでください。** お客様の社名、件数、金額、お客様の声、受賞歴、資格、スタッフの人数などを作らないこと。文章を足すときは、下の「確定している事実」の範囲で。
